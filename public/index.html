About

The RunIT Integration Suite Essentials (RISE) helps manage SAP Integration Suite efficiently. It provides a user-friendly interface for managing integration packages, artifacts, and deployment processes.

Instructions

How to use the Tranport management tool:

  1. Click "Transport Management" to begin.
  2. Enter Source & Target CPI credentials.
  3. Select the Integration Packages.
  4. Choose the Artifacts to transport.
  5. Review configurations & confirm the transport.

How to use the Export Log tool:

  1. Click "Export Logs" to begin.
  2. Enter CPI credentials.
  3. Select the Parameters.
  4. Choose the Artifacts for Logs.
  5. Review configurations & export the Log.
